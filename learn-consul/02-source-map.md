## How the "Now" rows connect (one paragraph)

`Agent.Start` builds `local.State` and `ae.StateSyncer`, then either `consul.NewServer` or `consul.NewClient` as `delegate`. A registration enters via `HTTPHandlers.AgentRegisterService` → `Agent.AddService` → `local.State`, and `ae.StateSyncer` turns it into a `Catalog.Register` RPC through `delegate.RPC` (client: `router` picks a server; server: in-process). On the server, `Catalog.Register` vets ACLs and calls `raftApply`, which goes through `hashicorp/raft` into `fsm.Apply` → `state.Store.EnsureRegistration`, which commits a memdb transaction at that Raft index and publishes change events. A consumer's `HealthServiceNodes` becomes `Health.ServiceNodes`, which runs `blockingQuery` over `state.CheckServiceNodes` with the caller's consistency choice. Meanwhile Serf on every agent tracks membership; on the leader, `lanEventHandler` → `reconcileCh` → `reconcileMember` → `V1ConsulRegistrator` writes the `serfHealth` check through the same `raftApply` path, so a dead agent's instances become unhealthy in the catalog without any agent-side action.
